# PaperShelf

PaperShelf is a browser-based seminar paper planning tool for students and researchers who want to organize claims, quotes, and citations before drafting.

## What it does

- Builds a five-section paper outline: Introduction, Literature Review, Methodology, Discussion, and Conclusion.
- Stores source details and reusable quotes in a source shelf.
- Creates outline cards that connect a claim to a saved quote.
- Automatically formats simple in-text citations from source and page data.
- Saves work locally in the browser.
- Lets users mark each card as Writing or Done.
- Exports the outline as a Markdown file.

## Live link

https://nadyshlden-sketch.github.io/papershelf/

## How to use it

1. Open the live link in your browser.
2. Add sources and quotes in the Source Shelf.
3. Add cards to the paper outline, choose supporting quotes, and export the board when ready.

## Known limitations

- Data is saved only in the current browser through local storage.
- The app can only manage one paper outline at a time in the same browser.
- There is no citation search yet; users have to find and select each saved quote manually.
